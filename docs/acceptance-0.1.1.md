# 0.1.1 开发验收（2026-09-15）

新增：可信 Reply 附件读取、原代码任务所有者权限下的成果登记/缓存、Skill 与知识分别保存的任务及回执、失败修正与继续。已有知识、Skill、模型及配置不改写。

验证：单元测试覆盖任务/话题/用户隔离、缓存持久化、私有同内容文件隔离、保存任务持久化及修正限制、稳定操作标识防重复。真实 AstrBot 4.28.1 无网络集成验证引用附件、任务工具回调、原执行器不可用后读取缓存、知识失败且 Skill 成功后仅补存知识。前端使用文本节点显示回执，验证空目录和管理交互。

限制：只登记启用本插件且存在可信话题绑定的代码任务；升级前未登记且已过期的文件不能恢复。缓存只保存 Markdown/TXT，每文件最多 1 MiB，每任务最多检查 25 个文件。引用文件依赖平台适配器已经下载；无法下载时解释原因并请求有权限成员补发。多成果不是跨系统原子提交，必须逐项报告；原发起人在原话题继续。

不调用生产模型、不发送飞书测试消息。部署经过备份、锁、固定提交和健康检查；真实多人协作和模型对范围缺失的处理由用户验收。


## 2026-09-15 原生知识库与保存状态修复

- 知识始终存入 AstrBot 原生知识库；未登记文档可直接检索、读取全部索引文本，平台未知明确标记。
- 原生替换要求已读指纹；归档原索引文本但不将旧正文嵌回新文档。删除旧文档成功后才返回 saved。
- 保存任务持久记录，15 秒后返回 processing；调用方取消不取消后台写入，失败/重载可查询并用原计划重试。重启不自动重跑模型。
- 完成 96 个单元测试及 2 个页面测试；真实 AstrBot 4.28.1 离线测试覆盖原生查询/读取/替换、指纹冲突、重复请求、保存状态及现有团队技能流程。
- 无真实聊天消息发送、无生产模型调用。原生更新不是跨数据库原子事务，处理中和清理失败不得视为完成；不支持其他程序同时编辑管理中的文档。

## 2026-09-15 保存来源恢复修复

- 新任务在审核前持久保存已经选定的话题来源和通过工具读取的旧文档证据。
- `knowledge_save_retry` 按任务编号恢复原计划、原来源和旧文档证据；同一用户、同一话题、同一计划才能继续。
- 已验证跨消息重试、插件服务对象重建后恢复、不同用户/话题拒绝复用、改变计划不复用，以及无需再次选择来源即可完成真实 AstrBot 离线写入。
- 升级前已经失败的任务没有来源快照，不能从计划正文推测来源；Agent 应继续完成来源读取与选择后重试。
