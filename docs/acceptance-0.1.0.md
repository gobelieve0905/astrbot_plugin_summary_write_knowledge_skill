# 0.1.0 开发验收（2026-09-15）

范围：团队管理技能新增，不搬迁原生全局文件，不调整人格、插件启用范围、模型和账户权限。

自动验证：Python 单元回归、AstrBot 4.28.1 实际镜像无网络集成、前端 Node 交互测试、桌面/390px 页面视觉检查。覆盖个人/团队/项目与实例隔离、维护者权限、版本冲突、停用和撤权对固定版本的限制、正文回滚、失败事务回滚、普通成员安装、审核拒绝、附件缓存。

需用户在真实聊天验收：两人创建与复用；Meta 通用流程配合不同项目资料；引用旧话题附件；不同作者修改建议；启停及回滚；模型能否正确选择并完整读取 Skill。自动测试未调用生产模型或发送测试消息。

已知边界：自包含 Markdown，不能新增脚本执行权限；项目团队权限沿用现有项目会话访问范围；团队共享限定同一平台实例和机器人。附件缓存从本版开始，代码任务成果遵守原所有者权限及保留期限；不承诺恢复已过期旧文件。原生内置 Skill 在原技能页管理，团队 Skill 在新插件页面管理。

develop 固定提交经备份、部署锁和既有回滚入口部署；不合并 main、不操作标签。
