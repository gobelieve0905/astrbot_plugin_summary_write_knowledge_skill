代码不自动迁移原有原生库文档，不补抓未进入 AstrBot 历史的群聊发言，不全局安装 Skill。未部署生产、未创建测试/正式标签、未创建 GitHub Release 或 Cloud 送审。

## 复现

```sh
python3 -B -m unittest discover -s tests -v
uv tool run ruff check .
uv tool run ruff format --check .
bash tests/validate-isolated.sh <已授权的测试主机>
```
